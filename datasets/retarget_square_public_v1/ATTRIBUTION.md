# Attribution and redistribution audit

This file is intentionally not a blanket license for image pixels.

`retarget_square_public_v1` mixes per-file licenses. The authoritative author,
source page, license evidence URL, license URL, redistribution state, and
modification notice are recorded on every `source_manifest.csv` row. CC BY and
CC BY-SA files require attribution and a change notice; derived CC BY-SA output
must use the same or a compatible license. Copyright licenses do not grant
personality, privacy, trademark, or endorsement rights.

The current candidate freeze has not completed the required per-image source
page, content-safety, scene, duplicate, and non-copyright review. Therefore no
candidate in this version is represented as publicly redistributable. Generate
a final attribution table only after all rows have
`public_release_eligible=true` and the strict finalizer passes.

Open Images annotations are CC BY 4.0, while image rows advertise CC BY 2.0 and
still require per-image confirmation against the original landing page. The
annotations are evaluator-only evidence and are not fed to generation methods.
