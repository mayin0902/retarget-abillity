# 文档入口

当前目录只保留接手、安装、运行、评审、数据和一份结果基线所需文档。

## 建议阅读顺序

1. [HANDOFF_OUTLINE.md](HANDOFF_OUTLINE.md)：十分钟讲解提纲；
2. [HANDOFF_DETAILED_GUIDE.md](HANDOFF_DETAILED_GUIDE.md)：架构、OCR/检测比较、Rule 公式、Agent、输入输出和迭代；
3. [runbooks/WINDOWS_INSTALL.md](runbooks/WINDOWS_INSTALL.md)：公司 Windows 电脑从零安装；
4. [runbooks/RUN_ONE_OR_BATCH.md](runbooks/RUN_ONE_OR_BATCH.md)：单图、已有候选、批量、Agent 和 UI；
5. [PLUGIN_STRATEGY_GUIDE.md](PLUGIN_STRATEGY_GUIDE.md)：如何换完整实现或只改参数，并保留历史；
6. [ALGORITHMS.md](ALGORITHMS.md)：七种重定向算法；
7. [REVIEW_GUIDE.md](REVIEW_GUIDE.md)：逐候选人工评分；
8. [DATA_AND_RESULTS.md](DATA_AND_RESULTS.md)：图片、Run、Release 和 Git 边界；
9. [reports/MOVIE60_STRICT_END_TO_END_REPORT.md](reports/MOVIE60_STRICT_END_TO_END_REPORT.md)：现有 Movie60 结果证据。

`adr/` 保存仍有效的架构决策。历史过程笔记不在当前 Git 树中；需要时从 Git 历史或本机 `local_data/` 追溯。
