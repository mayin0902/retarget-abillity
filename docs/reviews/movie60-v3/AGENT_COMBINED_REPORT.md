# Movie60 Rule + Agent v3 技术报告

## 最终结论

部署策略固定为 `movie60@3.2.2`：**Rule 负责最终候选与等级，Agent 负责中文高清视觉复核建议，不自动覆盖 Rule**。

Agent 仍逐任务读取原图、7 个候选、Rule 完整排名与 Rule Top1，提出最多 2 个 challenger，检查语义变化、人物/动物肢体、文字与 Logo、刚性物体和不物理形变。15 个冻结代理留出任务显示，当前 Agent 自动选图不够稳定，因此部署时将其自主权收回到建议层。

## 证据边界

- 420 个候选标签是“用户粗审认可的大模型建议”，不是逐候选人工真值。
- 45 个任务用于开发，15 个任务在策略冻结后只打开一次作为代理留出集。
- 真实人工记录只有 18 个任务、126 个候选，单独保存，未冒充本报告分母。
- 留出集已经用于三条预声明路线的部署选择，因此此后没有剩余独立验证集。

## 三条路线如何工作

```text
原图 + 7 个 1:1 候选
        |
        v
OCR / 人物 / 商品 / Logo / 结构与变换安全指标
        |
        v
Rule：7 候选连续分数、A/B/C/D、完整排名、Top1
        |
        v
Agent：原图语义 + 7 候选 + Rule 完整排名
        |
        +--> 最多 2 个 challenger
        |
        v
原图 vs Rule Top1 高清复核
原图 vs challenger 高清复核
Rule Top1 vs challenger 高清配对
        |
        v
语义/文字/人物/商品/Logo/物理合理性证据
        |
        +--> Agent-only：采用 Agent 建议（仅评测）
        +--> Combined 3.2.1：门禁允许时覆盖（实验）
        +--> 3.2.2：保留 Rule，Agent 证据进入人工复核（部署）
```

## 开发集结果（45 个任务）

“所选候选 AB”表示该路线选中的图在代理标签下可直接使用；“最佳方法命中”允许多个方法并列最好。

## 最终代理留出结果（15 个任务，只运行一次）

| 路线 | 精确等级 | AB/CD 一致 | 所选候选 AB | 最佳方法命中 |
|---|---:|---:|---:|---:|
| **Rule-only** | **60.00%** | **86.67%** | **100.00%（15/15）** | **86.67%** |
| Agent-only | 33.33% | 73.33% | 80.00%（12/15） | 60.00% |
| 3.2.1 实验 Combined | 53.33% | 86.67% | 86.67%（13/15） | 66.67% |
| **3.2.2 部署** | **60.00%** | **86.67%** | **100.00%（15/15）** | **86.67%** |

这组证据推翻了开发集上的 Agent 选图增益：Agent-only 少保留 3 张代理可用候选，实验 Combined 少保留 2 张。故从预声明的 Rule-only、Agent-only、Combined 中选择 Rule 主决策。没有据此继续调整 Rule 阈值或提示词。

留出任务的 Rule 所选候选代理标签全部为 A/B，因此这张任务级表没有 Rule 真 C/D 分母，Rule 的 C/D 召回为 `null`。候选级 105 张留出结果另见 `RULE_PROXY_HOLDOUT_REPORT.md`，不可与任务级选图指标混算。

## 版本迭代

- `3.0.0`：引入人类偏好 Rule、原图对照高清复核与 Rule 锚定覆盖。
- `3.1.0`：扩充人物关系、标题/Logo、刚性物体案例，最多 2 个 challenger。
- `3.2.0`：加强场景门禁、保护指标、局部高清图和证据去重。
- `3.2.1`：Agent 仍可选图，但 Combined 等级改用所选候选的 Rule metric；视觉证据确定性重放，0 次新模型调用。
- `3.2.2`：部署冻结；Rule Top1 不再被 Agent 自动覆盖，Agent 建议和高清证据仍完整保存。
