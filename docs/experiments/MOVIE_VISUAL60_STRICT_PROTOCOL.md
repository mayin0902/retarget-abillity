# Movie Visual 60 冻结实验协议

## 分母

- 60个源图，目标统一为1:1、1536×1536；
- 人物、电影海报、影片画面、视频封面各15张；
- Calibration每类5张，共20张；Validation每类10张，共40张；
- 七传统候选：Warp、Crop、限额/完整Seam、限额/完整Mesh、Seam+Scale；
- 60×7=420候选必须完整，失败也保留在分母。

## 自动评分

- 源图和每张候选独立执行相同检测器；
- 输出Quality、OCR、人脸、人物、商品/Logo、结构、几何和资源证据；
- Proxy A/B/C是路由证据，不是人工等级；
- Direct Warp按实际各向异性设等级上限；Seam/Mesh的局部扭曲必须另做视觉复核。

## Rule锚定视觉Agent

1. Rule输出完整七候选排名和Rule Top1；
2. Agent每个Task单独调用，看到原图、七候选、完整Rule排名和指标；
3. Agent只提出challenger，不能直接覆盖最终选择；
4. Rule Top1必须进入高清复核；不同challenger也进入高清复核；
5. 海报、多人、商品/Logo图增加文字、人脸、人物和主体高清局部；
6. `core_content_preserved=false`、关键文字召回下降或主体计数下降时，禁止推翻可用Rule A/B；
7. 只有视觉证据明确、无矛盾且候选等级更好时允许覆盖；否则回退Rule；
8. 单Task两分钟软目标，模型请求120秒超时。

## A/B/C/D

- A：关键内容完整自然、构图可直接使用；合理缩放或重新排版本身不扣分；
- B：存在轻微可见问题，但不妨碍上传或只需小修；
- C：主体、文字、人物、结构或构图有实质损伤，需要明显返工；
- D：严重缺失、错字、身份变化、大面积形变或技术损坏。

`UNSAFE`只是风险证据，不是等级上限；`SUCCESS`也不能覆盖肉眼可见的Warp、Seam或Mesh形变。

## AIGC

- 只有传统路线均存在实质问题时才进入计划；
- 素材必须允许第三方外发，预算和幂等门禁必须通过；
- 每Task最多一次，全局最多20个付费Task，硬预算12元；
- 保存技术状态、原生图、标准评测图、wall和可能计费状态；
- 失败回退传统Top1；成功图重新检测并做独立高清复核；
- 同时报成功图A/B率与完整计划分母A/B率。

## 校准门禁

- 辅助视觉预审不冒充项目人员人工标签；
- 只使用Calibration20更新阈值、规则或Skill；
- 冻结后Validation40只运行一次，不回看调参；
- 人工异级用于排序正确率，同级用于机器分差稳定性；
- 所有新版本使用新Evaluation/Agent/Review ID，不覆盖冻结结果。
