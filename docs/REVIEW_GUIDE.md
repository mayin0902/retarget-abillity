# 人工评审指南

## 1. 评审对象

Movie60有60个任务，每个任务包含原图和七个 `1536×1536` 传统候选，共420张候选。评审者需要
逐候选评分，而不是只评价机器Top1。页面显示Rule分数、Agent分析和辅助模型建议，因此不是盲测；
这些信息只用于定位问题，人工必须点击高清图独立判断。

重点20张另有Rule、Agent和AIGC路线复评。AIGC没有成功回图时记技术N/A，不按图像质量判C。

## 2. 评分原则

目标是判断图片能否用于实际上传，不是要求目标图与原图像素一致：

- 改成1:1、元素合理缩放、位置变化或重新排版本身不扣分；
- 主体自然且完整、文字可读、整体美观，即使构图与原图不同也可以给A；
- 轻微背景裁切、留白变化或非关键形变不影响上传时可给A或B；
- 人物/身体、文字、Logo、商品、建筑线或大面积区域发生肉眼明显扭曲时必须降级；
- 检测器或OCR与高清完整图冲突时，以高清完整图和人工判断为准，并记录检测误差。

## 3. 建议步骤

1. 先看原图，确认主体、关键文字、人物、商品/Logo和结构线；
2. 逐张打开七个候选高清图；
3. 给每个候选A/B/C/D/Skip；
4. 填主体完整、文字完整、几何自然、人脸/商品保护、版式平衡、整体可用六项细分；
5. 选择问题类型并填写具体理由；
6. 从A/B候选中选择一个或多个并列最佳；
7. 保存当前任务，再进入下一张。

推荐理由格式：

> 建议给A，原因：主体自然且均保留，文字无问题；即便背景略有裁切，也不影响整体上传，
> 不应仅因画布比例或排版变化给C。

## 4. 等级

| 等级 | 定义 | 判断重点 |
| --- | --- | --- |
| A | 可直接使用 | 主体、关键文字和视觉表达完整自然，整体美观 |
| B | 可用或小修可用 | 有可见小问题，但不妨碍主要信息和实际上传 |
| C | 需要明显返工 | 关键内容、人物、文字、结构或构图有实质问题 |
| D | 不可用 | 严重缺失、错字、身份变化、大面积扭曲或技术损坏 |
| Skip | 无法判断 | 文件损坏、证据不足或场景不适用 |

A+B均统计为通过。人工可以比当前机器阈值宽松，但必须写出“问题为什么不影响使用”。

## 5. Rule、Agent和辅助建议怎么看

- **Rule判分**：确定性指标和完整七候选排名；它可能误惩罚改版，也可能漏掉视觉扭曲；
- **Agent判分**：比较原图和候选的语义、人物、文字、结构和构图；Schema失败时回退Rule；
- **辅助模型建议**：已有高清复核的候选显示建议等级和理由，未复核候选明确显示待复核；
- **人工结论**：唯一用于后续校准的标签，不应复制机器文字作为理由。

## 6. 同级和并列最佳

- 排序正确率只统计人工等级不同的候选对；
- A=A、B=B、C=C、D=D不算机器排对或排错，只统计连续分差中位数和P90；
- 一个任务全部同级时不进入Top1命中率，另报机器最高分减最低分；
- 若Crop=A、Seam=A，两者都是人工最佳，机器选中任意一个均命中。

`local_data/movie60-review-v1/focus20/review.csv`。同一Reviewer ID可断点续评。
