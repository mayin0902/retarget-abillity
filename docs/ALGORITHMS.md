# 七条重定向路线

## 1. 统一输入和约束

七种正式候选共享同一次保护分析，输入均为原始 RGB 像素、目标尺寸、`importance_map`、
`tolerance_map` 和冻结参数。`importance_map` 越高表示越不能破坏；`tolerance_map` 越高表示
越适合压缩或裁切。所有方法输出精确 `1536×1536` PNG，并记录变换、耗时、资源和失败原因。

## 2. Direct Warp

直接把整图重采样到目标尺寸。它速度快、信息不丢失，但宽高比变化大会让人脸、商品和文字
变形。它是最重要的失真对照，不是推荐默认值。

## 3. Protected Crop

在满足目标比例的滑动窗口中，最大化保护内容保留、最小化裁切损失，然后只对裁切窗口做
等比缩放。它通常没有几何形变，但可能截断边缘文字或人物。窗口选择与候选生成是确定性的。

## 4. Full Seam

`seam_full` 是不限固定条数的内容感知 Seam Carving：

1. 在最长边受限的代理图上计算 Scharr 梯度、保护权重和可压缩权重；
2. 使用 forward-energy 动态规划逐条寻找接缝；
3. 宽或高方向按达到目标比例所需数量完整移除，而不是旧实现的固定上限；
4. 同步裁减源坐标图，最终只从原始高分辨率图片做一次 Lanczos/remap 渲染。

代理图控制计算量，但最终结果不是把低清代理图放大。每条接缝还记录保护命中均值和峰值，
便于发现穿过文字/人脸的问题。极端比例下 Seam 仍可能造成重复纹理、弯曲直线或字符缺笔，
因此必须保留保护命中和 OCR 重检门禁。

`seam` 是原有固定限额方法。它最多按轴移除冻结数量的接缝，之后用等比/非等比缩放补齐；
虽然不如 `seam_full` 完整，但在极端比例下往往能减少大量接缝穿过文字和人物的累积破坏。
因此它从 `cn_square_v2` 起重新成为正式候选，而不再只是隐藏的回归实现。

## 5. Full 2D Mesh

`mesh_full` 把源图划分为二维三角网格，基于保护区域刚性、局部等比例倾向、平滑项和边界锚点
构建加权最小二乘问题，分别求解目标顶点的 X/Y 坐标。求解后检查所有三角形有向面积；如果
发生 fold-over，则逐步混合回均匀网格，直到拓扑有效。最后对每个目标三角形做逆向坐标映射。

它区别于旧 `mesh` 的轴向近似：保护物体可以在二维局部保持更高刚性，背景承担更多形变。
它仍不是论文级视频时序/显式物体分层 Mesh；当前范围是单图、二维、可审计 CPU 实现。

原有 `mesh` 使用单调轴向网格和保护区加权，表达能力较弱，却也更不容易产生复杂的二维局部
弯折。`cn_square_v2` 将它与 `mesh_full` 同时保留，让规则和视觉 Agent 依据实际图片选择。

## 6. Seam + Scale

`seam_scale` 使用与 Full Seam 相同的 forward-energy 和坐标图，但只由 Seam 承担一部分比例
变化，其余由全局高质量重采样承担。它通常比 Full Seam 更快、局部伪影更少，同时比 Direct
Warp 减少主体拉伸。该方法保留是为了在质量和时延之间形成实际可选项。

## 7. 规则评分与 Agent 评分

规则评分把候选 OCR 保留、人脸/人物/商品/Logo 保护、结构、裁切、形变和运行失败等代理指标
组合成可回放 Quality。它便宜、稳定、可解释，但无法充分判断“海报整体是否还像原作品”。

视觉 Agent 每个 Task 单独接收一张保持原宽高比的 SOURCE、七个候选、传统指标摘要和版本化
Skill。它必须输出当题全部候选的完整排序、
选中候选、可用性、问题标签和解释；响应不合 Schema、排序不完整、超时或达到调用上限时，
均安全回退到规则结果。Agent 的目的不是替代指标，而是利用语义比较纠正规则的盲点。

Skill 版本独立于代码，评审反馈只能通过新版本更新，不能静默改历史 Run 的判定依据。
`UNSAFE` 只是保护指标发出的风险证据，不是人工等级上限：视觉上关键区域无实质损坏时仍可判
A；反之，标记为 `SUCCESS` 的结果若有拉伸、接缝、人物、文字、商品或结构线变形，也必须降级。

## 8. AIGC 回退

SeedDream 不是第六个常规候选。只有传统候选不可接受、Agent 建议生成、素材允许第三方出域、
预算尚有余额时，Router 才能为单个 Task 触发一次调用。Provider 在请求前冻结幂等键和预算，
对跳转、私网 URL、MIME、尺寸、像素解码和正方形结果做校验。当前 CN60 商业素材禁止外发，
因此不会用 fixture 或未授权图片伪造 AIGC 结果。

## 9. 仍需通过评测回答的问题

- Full Seam 是否在中文密集字海报上优于 Crop；
- Full Mesh 的结构保护是否足以抵消局部拉伸；
- Agent 相对规则选择的成功率提升是否稳定；
- 同一人工等级内，机器 Quality 是否过度拉开；
- 付费生成的真实增益是否覆盖其成本和时延。

这些是实验结论，不是实现完成后自动成立的事实。
