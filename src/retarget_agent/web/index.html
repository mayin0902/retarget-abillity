B
小修可用

主体与信息完整，只有轻微形变、留白或构图问题，不需要重新生成。

C
明显返工

核心内容尚在，但有明显形变、裁切、文字或构图问题，需要重新处理。

D
不可使用

关键主体或文字丢失、严重变形，或者存在无法接受的技术失败。

Skip

候选缺失、源图本身不可判读，或当前任务不具备公平评分条件。
